# Exam Anxiety & Student Performance

## Setup

1. Create and activate a virtual environment, then install dependencies with `pip install -r requirements.txt`.
2. Copy `.env.example` to `.env` and set `SUPABASE_URL` and `SUPABASE_KEY` to your Supabase project values. Set `FLASK_SECRET_KEY` to a random secret for deployments.
3. Create the table below in the Supabase SQL editor.
4. Run locally with `flask --app app run`, then open `/` for the survey or `/dashboard` for results.

```sql
create table public.survey_responses (
  id bigint generated by default as identity primary key,
  anxiety_score integer not null check (anxiety_score between 1 and 30),
  study_hours double precision not null check (study_hours between 0 and 24),
  exam_score double precision not null check (exam_score between 0 and 100),
  grade_bracket text not null check (grade_bracket in ('A', 'B', 'C', 'D', 'F')),
  created_at timestamptz not null default now()
);
```

For production, configure Supabase row-level security and policies appropriate to your deployment. The app's server-side Supabase key must be kept private and must never be exposed to the browser.
